## 1. 安装 Miniconda

```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh -b -u -p $HOME/miniconda3
/root/miniconda3/bin/conda init bash
source ~/.bashrc
# 接受 ToS
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r
```

## 2. 创建环境并安装推理服务

```bash
conda create -n Qwen python=3.11 -y    # 若 vLLM 0.19+ 要求 3.12，则改为 3.12
conda activate Qwen

# vLLM（用 uv 自动选匹配的 PyTorch + CUDA）
pip install uv
pip install uv -i https://pypi.tuna.tsinghua.edu.cn/simple/          # 默认源慢/失败时
uv pip install -U "vllm>=0.19.0" --torch-backend=auto
# 默认源失败/慢时，改用镜像源重装：
uv pip install -U "vllm>=0.19.0" --torch-backend=auto -i https://mirrors.aliyun.com/pypi/simple
uv pip install -U "vllm>=0.19.0" --torch-backend=auto -i https://pypi.tuna.tsinghua.edu.cn/simple

# 验证 CUDA
python -c "import torch; print('CUDA:', torch.cuda.is_available()); print('GPUs:', torch.cuda.device_count()); print(torch.cuda.get_device_name(0))"

# Open WebUI（网页对话界面）
pip install open-webui
pip install open-webui -i https://pypi.tuna.tsinghua.edu.cn/simple   # 默认源慢/失败时
open-webui serve --host 0.0.0.0 --port 8080
# 访问：http://192.168.18.133:8080

# 附加包（向量/模型转换用）
pip install sentence-transformers onnx onnxruntime openvino -i https://mirrors.aliyun.com/pypi/simple
pip install "sentence-transformers<4.0" -i https://mirrors.aliyun.com/pypi/simple
```

## 3. 下载模型（ModelScope）

先装工具：

```bash
pip install modelscope
pip install modelscope -i https://pypi.tuna.tsinghua.edu.cn/simple   # 默认源慢/失败时
```

## 4. 后台下载与查看

```bash
# 后台下载示例（可放任意需要长时间下载的模型）
su - root -c "nohup bash -c '
source /root/miniconda3/etc/profile.d/conda.sh
conda activate Deepseek
modelscope download --model deepseek-ai/DeepSeek-V4-Pro --local_dir /mnt/nvme0n1/model/Deepseekv4pro
' > /root/deepseek_dl.log 2>&1 &"

tail -f /root/deepseek_dl.log        # 查看下载日志
ps aux | grep modelscope             # 查看后台下载进程
```
