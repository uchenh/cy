## 三、这套系统的形态（一句话）

**边界防火墙 + 1 台三层业务交换机 + 1 台二层管理交换机 + 1 台独立 IB 算力交换机 + 10 台服务器**（1 管理/登录 + 8 GPU + 1 存储），
管理网 `192.168.10.0/24`（VLAN 10）与业务网 `192.168.11.0/24`（VLAN 11）**共用一台 S6880 做三层网关**，
出口为**电信 + 联通双线主备**，客户经 **SSL VPN** 从公网接入管理网与业务网，
计算通信走**完全独立**的 200G InfiniBand fabric（`10.20.0.0/16`）。

## 四、两条必须记住的前提

1. **本期交换机各只有 1 台，不做堆叠** —— 任何 `irf` / MAD 内容属二期限定，现场**不要执行**（做法归档在《HPC集群网络配置方案.md》§10.4 附录）。
2. **单机形态没有设备级冗余** —— 每个阶段结束必须 `save force` 落盘，关键配置离线备份。

- 本目录是**整理版交付文档**，不替代 `docs/操作/` 五份权威手册；**命令有出入时以 `docs/操作/` 为准**。

- `docs/配置.md`、`docs/文档.md` 等**含设备口令的原始笔记**不属于本目录；本目录正文**不复制设备 admin 口令明文**，只指向《配置命令执行手册.md》阶段 0。
- 客户可直接阅读的版本见 `docs/客户使用说明.md`（已剥离全部设备管理内容）。
