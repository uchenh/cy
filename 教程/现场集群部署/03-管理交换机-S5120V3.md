# 03 · 管理交换机 S5120V3-52P-SI

> **设备角色**：纯二层接入，承载 **VLAN 10（管理网）**，把 10 台服务器的 BMC/带外口汇聚后经 trunk 上送业务交换机。
> **配套**：《配置命令执行手册.md》阶段 0 / 3 / 8；《HPC集群网络配置方案.md》§4。

---

## 1. 设备概况

| 项 | 值 |
|---|---|
| 型号 | H3C **S5120V3-52P-SI** |
| 物理端口 | **48 × 千兆电口（GE1/0/1–48）+ 4 × 1000BASE-X SFP（GE1/0/49–52）** |
| 软件体系 | Comware 7（命令语法与 S6880 相同） |
| 数量 | **1 台（单机，不堆叠）** |
| 主机名 | `MGMT_SW`（执行手册阶段 3 的 `sysname`） |
| 管理地址 | **`Vlan-interface10` = 192.168.10.251/24**（**该型号无带外管理口**） |
| 承载 VLAN | VLAN 10（access，BMC）、VLAN 11（随 trunk 透传） |
| 是否三层 | 名义上是二层设备，但**官方规格支持 IPv4/IPv6 静态路由** ⇒ 能配一条 VPN 回程路由，让本机也能被客户远程访问 |

> ⚠ **两个反直觉点**：
> 1. `S5120V3-52P-SI` **没有带外管理口** —— `display interface brief` 里只有 `GE1/0/1–52`，没有 `MGE`。照抄 S6880 的 `interface M-GigabitEthernet0/0/0` 会在这一步报 `% Wrong parameter found`（2026-09-23 现场实际踩到）。
> 2. 那 4 个 SFP 口是 **1000BASE-X 千兆**，不是万兆 —— 接口名是 **`GigabitEthernet1/0/49`–`1/0/52`**，不是 `Ten-GigabitEthernet`。（带 1G/10G SFP+ 的是同系列 `52S-SI`。）

---

## 2. 接口配置（逐项）

### 2.1 管理地址（配在 VLAN 接口上）

```
vlan 10
 description MGMT-BMC
quit
vlan 11
quit

interface Vlan-interface10
 ip address 192.168.10.251 255.255.255.0
quit
```

> 因为无带外口，管理 IP 只能落在 **`Vlan-interface10`** 上。前提是先 `vlan 10` 把 VLAN 建出来。

### 2.2 上联业务交换机（单链路 trunk）

```
interface GigabitEthernet1/0/48
 port link-type trunk
 port trunk permit vlan 10 11
quit
```

| 项 | 值 |
|---|---|
| 本端 | `GigabitEthernet1/0/48`（**千兆电口**） |
| 对端 | S6880 `Twenty-FiveGigE1/0/48`（SFP28 口插 `1000BASE-T` 光转电模块） |
| 介质 | 普通网线（Cat6/Cat6a） |
| 速率 | 1G（本侧电口本身就是千兆，**无需配 speed**；速率强制在 S6880 侧做） |
| 放行 | VLAN **10 和 11** |

> **为什么不用那 4 个 SFP 口做上行**：它们是千兆 SFP，而 S6880 全是光口。用"网线 + 光转电模块"把两端都变成电口，省掉一对 1G 光模块和 LC 光纤。

### 2.3 BMC 下联口（access VLAN 10）

```
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/10
 port access vlan 10
 description BMC-pool
quit
```

| 端口 | 节点 BMC | BMC IP |
|---|---|---|
| `GE1/0/1` | mgmt01 | 192.168.10.11 |
| `GE1/0/2` | stg01 | 192.168.10.12 |
| `GE1/0/3`–`GE1/0/10` | gpu01–gpu08 | 192.168.10.13–.20 |
| `GE1/0/11`–`GE1/0/12` | 如需同步现场扩展，对应 S6880 的 `1/0/11`–`1/0/12` | — |

> **整段统一 access VLAN 10、不绑定具体节点** ⇒ 换插口不用改配置，只需清理旧残留（原堆叠方案在 `1/0/11`–`1/0/13` 留过 VLAN 11，见《配置命令执行手册.md》阶段 2 提示）。

### 2.4 空置端口

| 端口 | 说明 |
|---|---|
| `GigabitEthernet1/0/49`、`1/0/50`、`1/0/52` | 空置（原 IRF 互联口 / 备用） |

## 3. 路由

管理交换机**不需要任何路由即可让 BMC 上网**：路径是
`BMC → S5120V3（VLAN 10 二层）→ trunk → S6880（Vlan-if10 网关）→ 防火墙`。

**唯一需要配的一条路由是 SSL VPN 回程**（2026-09-24 现场补配）：

```
ip route-static 192.168.99.0 24 192.168.10.254
```

| 为什么需要 | 说明 |
|---|---|
| 目的 | 让**管理交换机本身**也能被 VPN 客户访问（`ssh admin@192.168.10.251`） |
| 下一跳 | `192.168.10.254`（S6880 的 `Vlan-if10`，即管理网网关） |
| 前提 | 该型号官方规格支持 IPv4/IPv6 静态路由，**不是纯二层设备** |

> 若只想让客户访问服务器而不访问交换机，这条可以不配；但本项目客户需要"管理 + 使用"，故配上。

## 4. Console 首次配置（阶段 0 的差异写法）

S5120V3 **不能照抄** S6880 的管理口那两行，其余相同：

```
system-view
undo telnet server enable
ssh server enable
local-user admin class manage
 password simple <强口令>
 service-type ssh
 authorization-attribute user-role network-admin
quit
line vty 0 63                      # 该型号若报范围错误，改用 line vty 0 4
 authentication-mode scheme
 protocol inbound ssh
quit

# ⚠ 下面三行是本型号的写法（没有 M-GigabitEthernet 口）
vlan 10
interface Vlan-interface10
 ip address 192.168.10.251 255.255.255.0

save force
```

**首配阶段的 SSH 验证方法**：该设备没有带外口，**改插它任意一个下联口**（`GE1/0/1`–`1/0/10` 已划入 VLAN 10），笔记本配 `192.168.10.110/24`，然后 `ssh admin@192.168.10.251`。

## 5. 验证

| 检查项 | 命令 | 预期 |
|---|---|---|
| VLAN 已建 | `display vlan` | `1(default), 10-11` |
| VLAN 10 成员口 | `display vlan 10` | `GE1/0/1–1/0/10` 为 Untagged 成员 |
| 管理地址 | `display ip interface brief` | `Vlan10 = 192.168.10.251` |
| 上联口 | `display interface brief` | `GE1/0/48` UP（对端 S6880 `1/0/48` 也 UP） |
| 本机可达 | 笔记本接任一下联口 | `ssh admin@192.168.10.251` 成功 |
| 经 VPN 可达 | VPN 客户端 `Test-NetConnection 192.168.10.251 -Port 22` | **`TcpTestSucceeded: True`**（2026-09-24 实测） |
| 回程路由 | `display ip routing-table` | `192.168.99.0/24` 指向 `192.168.10.254` |
| 配置落盘 | `save force` | 每次改动后执行 |

## 6. 关键参数速查

| 参数 | 值 |
|---|---|
| 管理地址 | `Vlan-interface10` = 192.168.10.251/24（无带外口） |
| 上联口 | `GE1/0/48`，trunk VLAN 10/11，千兆电口 |
| BMC 口 | `GE1/0/1`–`GE1/0/10`，access VLAN 10 |

| 冗余 | 无（单机） |

## 7. 本篇相关坑

1. 没有带外管理口，管理地址配 `Vlan-interface10`（先建 VLAN 再配接口）。
2. 4 个 SFP 口是千兆，接口名是 `GigabitEthernet`，不是 `Ten-GigabitEthernet`。
3. 上行走 `1/0/48` **电口**，不要在 SFP 口上折腾（那需要另买 1G 光模块）。
4. 上行速率只能 1G，速率强制在 S6880 侧做（`speed 1000`）。
5. 该型号没有 `MGE` 口，`display interface brief` 只有 `GE1/0/1–52`。
