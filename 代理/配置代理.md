# 配置代理

> 以下为不同网络环境下可用的代理地址，按需选用其一即可（后设置的会覆盖先前设置的）。

## 取消代理

```bash
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY
```

## 查看当前代理

```bash
env | grep -i proxy
```

## 设置代理（按网络环境选择其一）

```bash
# 192.168.12.231
export http_proxy="http://192.168.12.231:7897"
export https_proxy="http://192.168.12.231:7897"

# 192.168.12.187
export http_proxy="http://192.168.12.187:7897"
export https_proxy="http://192.168.12.187:7897"

# 10.0.5.173
export http_proxy="http://10.0.5.173"
export https_proxy="http://10.0.5.173"

# 192.168.12.1
export http_proxy="http://192.168.12.1:7897"
export https_proxy="http://192.168.12.1:7897"

# 192.168.1.97
export http_proxy="http://192.168.1.97:7897"
export https_proxy="http://192.168.1.97:7897"
```
