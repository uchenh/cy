# Hy4 preview vs DeepSeek V4-Flash vs GLM-5.3-Flash 对比

> **一句话结论**：三个模型不属于同一档位，但差距远小于分数表看起来的样子。**跨厂商基准分数的噪声约 ±5 分**，而三者在 Terminal Bench 2.1 上的全距只有 2.7 分——**这个排序在统计上不可靠**。真正可靠的差异在价格与多模态：**GLM-5.3-Flash 是本次对比的实际赢家**——第三方 AA 智能指数 57 分（V4-Flash 52 分），原生多模态，且在精算的 5 类场景中 3 类最便宜；V4-Flash 的 0.05 元缓存命中价只在「长输入 + 命中率 > 83% + 低输出量」的窄窗口内才反超；Hy4 preview 以 4~6 倍价格换取长程软件工程任务的稳定优势，但仍是预览版且有过度自我验证的已知问题，且无任何第三方评分背书。

## 三、关键判据：跨厂商分数有多不可靠

这是本份对比里最需要读者理解的一节。**三家使用不同的评测脚手架（harness），分数不可直接相减。**

### 3.1 直接证据：同一个 DeepSeek 模型，两套分数

DeepSeek-V4-Flash 系列在自家 harness 与智谱 harness 下的得分差异：

| 基准 | DeepSeek 自家 harness | 智谱 harness（Vision-Exp） | 差值 |
|------|----------------------|---------------------------|------|
| Terminal Bench 2.1 | 82.7 | 83.9 | +1.2 |
| DeepSWE | 54.4 | 59.3（v1.1） | **+4.9** |
| Toolathlon-Verified | 70.3 | 75.9 | **+5.6** |
| Agents' Last Exam | 25.2 | 27.3 | +2.1 |

> 说明：Vision-Exp 与 V4-Flash 正式版在纯文本能力上官方称"持平"，因此这两列可视为**同一能力模型在不同脚手架下的两次测量**。

**结论：换一套 harness，同一模型在不同基准上波动 1.2~5.6 分。**

### 3.2 由此得到的判读规则

| 观察到的分差 | 判读 |
|-------------|------|
| < 3 分 | **噪声范围内，不构成排序依据** |
| 3~6 分 | 弱证据，需第三方同口径复现 |
| > 6 分 | 可视为真实差异 |

应用这条规则重新审视第二节的表格：

- **Terminal Bench 2.1 全距 2.7 分 → 三者实质持平**，"Hy4 > GLM > DeepSeek" 的排序不可信。
- **Toolathlon-Verified 全距 8.1 分 → GLM-5.3-Flash 的 78.4 大概率真实优于 V4-Flash 的 70.3**，Hy4 的 74.1 居中。
- **DeepSWE 全距 9.9 分 → V4-Flash 的 54.4 明显落后**，Hy4（64.3）与 GLM（63.4，v1.1）持平且领先。注意 DeepSWE 版本可能不同（v1 vs v1.1），此结论强度下调。
- **AA 智能指数 57 vs 52 → 同口径第三方数据，可信**，GLM-5.3-Flash 综合智能确实高于 V4-Flash。

### 3.3 各家的评测配置

| 环节 | DeepSeek | 智谱 GLM | 腾讯 Hy4 |
|------|----------|----------|----------|
| Terminal Bench 2.1 | DeepSeek Harness 极简模式，max 档，top_p=0.95，temp=1.0 | Claude Code 2.1.207，temp=1.0，top_p=1，6h 超时 | **未公开** |

腾讯未公开评测脚手架，这使得 Hy4 的分数在跨厂商比较中可信度最低。

## 四、成本对比与场景测算

### 4.1 单价表（元 / 百万 tokens）

| 项 | Hy4 preview | V4-Flash 空闲 | V4-Flash 高峰 | GLM-5.3-Flash |
|----|-------------|---------------|---------------|---------------|
| 输入（缓存未命中） | 6 | 1.5 | 3 | **0.8**（限时 0.4） |
| 输出 | 18 | 4.5 | 9 | **2.8**（限时 1.4） |
| 输入（缓存命中） | 0.3 | **0.05** | 0.1 | 0.23 |

V4-Flash 峰谷时段：高峰 9:00–12:00、14:00–18:00（北京时间），其余为闲时。GLM-5.3-Flash 限时半价约至上线的两周后（2026-09-09 前后）。

**单价层面的直观对比**：
- 输出价：Hy4 是 GLM 的 **6.4 倍**、V4-Flash 高峰档的 **2.0 倍**、空闲档的 **4.0 倍**
- 输入价：Hy4 是 GLM 的 **7.5 倍**、V4-Flash 高峰档的 **2.0 倍**
- 缓存命中价：**V4-Flash 最低**，GLM 是它的 2.3~4.6 倍，Hy4 是它的 3~6 倍

### 4.2 场景测算：单轮会话成本

以下为脚本精算结果（元/轮，取公开标价，GLM 另列限时半价）：

| 场景 | Hy4 preview | V4-Flash 高峰 | V4-Flash 空闲 | GLM-5.3-Flash | GLM 限时半价 |
|------|-------------|---------------|---------------|---------------|--------------|
| A 输入 100K / 输出 2K / 命中 95% | 0.0945 | 0.0425 | **0.0213** | 0.0315 | 0.0267 |
| B 输入 100K / 输出 2K / 命中 99% | 0.0717 | 0.0309 | **0.0155** | 0.0292 | 0.0260 |
| C 输入 100K / 输出 10K / 命中 99% | 0.2157 | 0.1029 | 0.0515 | 0.0516 | **0.0372** |
| D 输入 20K / 输出 2K / 命中 50% | 0.0990 | 0.0490 | 0.0245 | 0.0159 | **0.0091** |
| E 输入 100K / 输出 2K / 命中 0% | 0.6360 | 0.3180 | 0.1590 | 0.0856 | **0.0428** |

### 4.3 临界点：V4-Flash 何时才比 GLM 便宜

缓存命中率是决定胜负的核心变量。下表为「V4-Flash 与 GLM 成本相等」时的缓存命中率——**高于该值 V4-Flash 更便宜，低于该值 GLM 更便宜**：

| 输入 / 输出 | V4-Flash 空闲 vs GLM 标价 | V4-Flash 空闲 vs GLM 半价 | V4-Flash 高峰 vs GLM 标价 |
|-------------|--------------------------|--------------------------|--------------------------|
| 100K / 2K | 83.4% | 90.8% | 99.7% |
| 100K / 10K | 98.9% | 不可达 | 不可达 |
| 50K / 2K | 87.3% | 95.6% | 不可达 |
| 20K / 2K | 98.9% | 不可达 | 不可达 |

**测算结论**：

1. **V4-Flash 的低价窗口比直觉窄得多。** 仅在「长输入 + 极高缓存命中率 + 低输出量」组合下占优：100K 输入 / 2K 输出时临界命中率 83.4%，看似可达；但输出升到 10K 或输入缩短到 20K，临界点立刻飙到 98.9%，实际不可达。
2. **V4-Flash 高峰档几乎从不占优。** 对 GLM 标价的临界命中率高达 99.7%~100%，意味着高峰时段用 V4-Flash 跑 Agent 任务，成本基本总是高于 GLM。
3. **GLM-5.3-Flash 在绝大多数真实场景最便宜。** 在输出密集（场景 C）与低缓存命中（场景 D、E）时优势最大——场景 E 下比 V4-Flash 空闲档便宜 46%、比 Hy4 便宜 85%。
4. **Hy4 preview 在所有场景均为最贵**，为最低价的 4.4~14.9 倍。

> 说明：GLM 限时半价约持续至 2026-09-09 前后；缓存命中价是否同步折扣未见官方说明，表中按不折扣保守计算。

## 五、能力边界差异

### 5.1 多模态

| 模型 | 状态 |
|------|------|
| GLM-5.3-Flash | **原生多模态**。视觉反馈可直接进入 Coding Loop——写完网页自行截图检查，做游戏进入实机观察，处理 PPT/PDF/DOCX/XLSX 时按最终视觉效果迭代。这是三者中唯一能把"任务完成"的判据从代码延伸到成品的模型 |
| V4-Flash | 文本版不支持视觉；另有 **V4-Flash-Vision-Exp**（8/21 上线）补齐视觉 Agent 能力，多模态 Agent 接近 Opus 4.8，纯文本能力与正式版持平 |
| Hy4 preview | **明确不支持**原生多模态，不能看图、识图、生图。图像类需用混元其他产品线 |

### 5.2 长上下文的有效利用率

| 模型 | 情况 |
|------|------|
| V4-Flash | **官方技术报告承认**：Max 档在 1M 下 MRCR 78.7、CorpusQA 60.5，**超过 128K 后性能开始下滑**。1M 适合当"可寻址仓库"，工作区建议放在 128K~256K |
| GLM-5.3-Flash | 稀疏+线性注意力混合架构专为降低长上下文成本设计，IndexPool 将索引器 4 个缓存向量压缩为 1 个。未公开长上下文衰减曲线 |
| Hy4 preview | Gated DSA 稀疏注意力 + IndexCache 跨层索引复用，官方称 1M "真的能跑"。**无第三方长上下文有效性验证** |

### 5.3 部署与私有化

| 模型 | 权重体积 | 硬件门槛 | 已知风险 |
|------|---------|---------|---------|
| Hy4 preview | 780GB（FP8 约 800GB） | 8 卡 H200/B200 单机可跑 | 每 token 需读约 49GB 权重，显存带宽压力大，超大批量吞吐成本高 |
| V4-Flash | 约 167GB（DSpark 融合权重） | 4 张高端卡可架起 | 社区反馈**并发一上来显存吃紧**，超长文本预填充慢；跑起来容易，稳定服务是另一回事 |
| GLM-5.3-Flash | 320B（BF16 版另发） | 支持 SGLang / vLLM / TokenSpeed | 发布仅 2 天，社区部署反馈尚不足。KV 缓存略大于 Kimi K3 与 V4-Flash（官方自述待优化） |

### 5.4 成熟度与已知问题

| 模型 | 状态 |
|------|------|
| Hy4 preview | **预览版**。官方自述：预训练和后训练仍有较大提升空间，存在**复杂任务的长思考和过度自我验证倾向**。第三方实测印证——会困在自我验证循环里需人工打断，思考效率不高。正式版未发布 |
| V4-Flash 正式版 | 正式版，但**长流程 Agent 是明确短板**：几百轮操作中错误易累积，需配套检查机制、结果验证器和人工审核。企业反馈两极——"整库检索、财报分析很好用" vs "Agent 任务基本没法用" |
| GLM-5.3-Flash | 正式版。已通过 ox-alpha 匿名身份在 OpenRouter / OpenCode 承受大规模真实负载测试，6 天处理 42 万亿 tokens 登顶。**已有大规模真实流量验证**，这是三者中最充分的一项 |

## 六、选型建议

### 6.1 决策清单

对照以下问题逐条判断：

| 判断项 | 选择 |
|--------|------|
| 需要看图 / 读视频 / 处理带视觉的文档与前端成品 | **GLM-5.3-Flash**（唯一原生多模态） |
| 任务是长程软件工程（多文件重构、仓库级修改、长链路调试） | **Hy4 preview**（DeepSWE 领先，激活算力最高） |
| 失败成本高、需要一次做对的关键决策任务 | **Hy4 preview** 或 V4-Pro 正式版 |
| 高吞吐粗活（整库检索、财报初筛、批量分类、草稿生成） | **GLM-5.3-Flash**（综合最便宜） |
| Agent 会话前缀极长且重复，缓存命中率 > 85% 且单轮输出量低 | **V4-Flash 空闲档**（缓存价 0.05 元）；不满足此窄窗口则 GLM 更便宜 |
| 已在腾讯生态（WorkBuddy / CodeBuddy / 元宝 / ima）内工作 | **Hy4 preview**（8/28–9/10 限免，深度协同） |
| 需要私有化部署且硬件有限 | **V4-Flash**（167GB 门槛最低）或 GLM（BF16 版） |
| 需要视觉 Agent + 已在用 DeepSeek 技术栈 | **V4-Flash-Vision-Exp** |

### 6.2 分层组合方案（推荐）

单模型选型不如分层：

1. **草稿层**：GLM-5.3-Flash 或 V4-Flash —— 检索、初筛、批量生成、草稿
2. **决策层**：Hy4 preview 或 V4-Pro 正式版 —— 关键路径、长程任务、失败成本高的环节
3. **验证层**：外部检查点 + 结果验证器 —— 任何模型跑几百轮长 Agent 都必须有

### 6.3 时间与价格窗口

- Hy4 preview：2026-08-28 起限免约两周（至 9/10 前后），Hy3 免费期延长至 9/30
- GLM-5.3-Flash：上线两周限时半价（输入 0.4 / 输出 1.4），约至 2026-09-09；GLM Coding Plan 每天限量发放 10,000 张体验卡
- V4-Flash：峰谷定价已生效，避开 9:00–12:00 与 14:00–18:00 可省 50%

### 8.3 必须注意的口径冲突

1. **DeepSeek V4 系列参数口径混乱**：部分媒体称 V4-Pro 为 671B/37B，另有称 1600B/49B，均不可靠。本文档采用官方模型卡的 284B/13B（V4-Flash，含 DSpark 为 304B）。
2. **AA 智能指数版本**：V4-Flash 有 50 与 52 两种引用。经与 GLM-5.2（53）、Gemini 3.6 Flash（52）的横向描述交叉验证，**52 为正确值**，50 系早期或笔误。
3. **AutomationBench 不可跨表比较**：智谱用 v1.0.6（含 null 类型修复），DeepSeek 用 Public 版，两者差距可能主要来自版本而非模型能力。
4. **DeepSWE 版本**：智谱明确标注 v1.1，DeepSeek 与腾讯未标注版本，跨厂商比较时结论强度需下调。
5. **Hy4 的 Agents' Last Exam 数值无法确认**：官方完整基准表为图片形式，数值无法可靠对齐，故标记为"未公开可靠值"。
6. **所有厂商自报分数均未经第三方独立复现**，AI 应用评测领域尚无统一强制披露标准。
