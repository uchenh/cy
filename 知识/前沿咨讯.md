## 维度二：模型部署与软件实操

### 4. 部署工具链新特性

- **vLLM v0.28.0（8/26）**：Shared-Expert Sharding（每 GPU 释放约 17GiB）；DeepSeek V4 稀疏 MLA 端到端 + AMD ROCm（gfx11/gfx950）；DCP 长上下文；`max_num_batched_tokens` →16384。**DSpark 自适应验证（8/14 博客）**：动态调验证长度免手调 `num_speculative_tokens`，并发 256 仍有收益、TTFT 改善约 60%。
- **Ray 2.58.0（8/23）**：Ray Serve LLM 的 **KV-cache-aware routing** 转正；TorchTPU backend；Ray Sandbox 可 gVisor 跑 Docker 镜像（Agent 沙箱部署）；修复嵌套 pickle RCE、token 认证绕过。
- **SGLang v0.5.18（8/22）**：新增 Muse Glimmer、Cosmos3 Edge、LTX-2.5 等模型家族；torch 2.13/triton 3.7.1/sgl-kernel 0.4.6。
- **Ollama v0.33.0 + Claude Desktop（8/21、8/25）**：可将 Claude Desktop 配为以 Ollama 作网关，直选本地/Qwen/DeepSeek/Kimi 模型，支持一键回退，贴合内网/离线 Agent 接入。
- 来源：vLLM https://github.com/vllm-project/vllm/releases/tag/v0.28.0 ；Ray https://github.com/ray-project/ray/releases ；SGLang https://github.com/sgl-project/sglang/releases ；https://ollama.com/blog/claude-desktop

### 6. 运维提效：GPU 弹性 + Linux AI 内核/驱动调优

- **GPU 弹性**：Karpenter + KEDA 节点/按需弹缩；ACK 支持基于 DCGM 指标（如 DCGM_CUSTOM_PROCESS_SM_UTIL）经 Prometheus Adapter + HPA 扩缩容；扩容优先用已 MIG/共享 GPU 节点、缩容设冷却并优雅终止。
- **内核/调度**：NUMA 感知约 10–30% 收益；governor 切 performance 约 5–15% 且降 TTFT；禁 deep C-states 优化 P99（idle +30–50W/socket）；THP=madvise 对 PyTorch 约 1–5%。
- **驱动注意**：Tesla 580.65.06（R580 LTS）——Hopper subrevision=3 且 VBIOS <96.00.68.00.xx 无法初始化；CUDA 13.3 Update 1。
